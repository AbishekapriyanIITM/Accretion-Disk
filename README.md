Accretion disks are matter trapped a huge object's gravity and orbit around them at high velocities, dispersing heat by energy. 
This project was aimed at understanding the accertion disks in a fluid dynamics perspective and developing a simple model based on navier stokes 
This was already done by several papers on this topic and my aim was choosing a simple model and see how it compared to observational data

![Equation](https://latex.codecogs.com/svg.image?\color{white}\nu\Sigma=\frac{1}{3\pi}\dot{M}\left[1-\beta\left(\frac{r_i}{r}\right)^{1/2}\right])

In this particular model, some of the parameters have to be empirically determined, that is why we have the code to do curve fitting with actual data.
